# MGT 1.0 — Robô assistido da Autovistoria

Esta atualização acrescenta uma extensão do Chrome que:

- recebe do MGT os dados do condomínio;
- abre o portal oficial da Autovistoria;
- digita logradouro, número, complemento e comunicado campo a campo;
- seleciona o bairro;
- pausa para o usuário digitar o CAPTCHA;
- lê a tabela de comunicados após a consulta;
- importa uma ou várias ocorrências para o MGT;
- ignora comunicados já cadastrados;
- mantém a geração de oportunidade bloqueada até existir ao menos uma autuação.

A automação é assistida e não tenta resolver ou contornar o código de segurança.
